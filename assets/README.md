# Assets folder

Ovdje čuvaj slike za PDF izvještaje:

- `pecat.png` - pečat agencije
- `potpis.png` - potpis

**Препоручене dimenzije:**
- Pečat: 150x150px (PNG sa transparentnom pozadinom)
- Potpis: 200x80px (PNG sa transparentnom pozadinom)

**Kako koristiti u PDF-u:**
```html
<img src="assets/pecat.png" alt="Pečat" style="width: 100px;">
<img src="assets/potpis.png" alt="Potpis" style="width: 150px;">
```
